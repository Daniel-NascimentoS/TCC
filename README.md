# TCC - Redes Neurais Bayesianas em Risco de Crédito

## Objetivo

Comparar métodos determinísticos e bayesianos para classificação de risco de crédito, com foco em:

- deicriminação;
- calibração;
- qualidade probabilística;
- quantificação de incerteza.

## Dados

Default of Credit Card Clients - Taiwan.

Fonte:
UCI Machine Learning Repository.

## Estrutura

- `data/` - dados
- `notebooks/` - análises exploratórias e experimentos
- `tests/` — testes
- `results/` — resultados
- `docs/` — documentação
